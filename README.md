# Kalter Krieg - Lernpfad

Statische Landingpage fuer eine Geschichtsstunde zum Kalten Krieg.

## Inhalt

- `index.html`: Landingpage mit Kalter-Krieg-Design und Entscheidungsspielen zu Korea, Kuba, Vietnam, Afghanistan, Grenada und Dekolonisierung.
- `IM_Rennfahrer_Lernspiel.html`: vorhandenes Lernspiel zu IM "Rennfahrer", lokal verlinkt.

## Unterrichtsidee

Die Schuelerinnen und Schueler starten auf der Landingpage. Links fuehrt eine Kachel zum Lernspiel ueber Spionage/Stasi. Der zweite Bereich fuehrt zu kurzen Entscheidungspfaden zu Konfliktfeldern des heissen Kalten Krieges.

In jedem Spiel waehlen sie eine politische Option. Danach sehen sie, welche Option historisch tatsaechlich gewaehlt wurde und welche Folge damit verbunden war.

## Veroeffentlichung

Das Projekt ist fuer GitHub Pages geeignet. `index.html` kann direkt als Startseite verwendet werden.
